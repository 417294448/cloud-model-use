Naming Conventions

Understand these patterns and instantly grasp any model name

ElementMeaningExample
gemini-X.Y version number Higher number = newer and stronger gemini-2.0 → 2.5 → 3 → 3.1 → 3.7
-pro Flagship enhanced, top reasoning gemini-3.1-pro-preview, gemini-2.5-pro
-flash Speed-optimized, balanced gemini-3.7-flash, gemini-2.5-flash
-flash-lite Cheapest and fastest lite gemini-3.5-flash-lite, gemini-3.1-flash-lite
-preview Preview (production-ready; 2-week deprecation notice) gemini-3.1-pro-preview

nano-banana (🍌) Image-generation family codename gemini-3-pro-image (Pro), gemini-3.1-flash-image (2)
-image Supports image output gemini-3.1-flash-image

-native-audio Native audio processing (Live API) gemini-2.5-flash-native-audio-preview-12-2025

-tts Text to speech gemini-3.1-flash-tts-preview
-transcribe Speech to text gemini-3.5-transcribe(-live)
